How to Install (Android Sideloading Guide)

Because you are downloading {{ .data.name }} for Android directly from our official website rather than an app store, Android requires manual installation (sideloading). Follow these simple steps to install:

  1. Download the APK: Tap the black "Download APK" button at the top of this page.
  2. Enable Install Permissions:
    • Go to your device's Settings.
    • Navigate to Apps > Special App Access (you might need to click the vertical three dots top right and select Special Access) > Install Unknown Apps (or search "Install unknown apps" in Settings).
    • Select your File Manager or My Files, and toggle on "Allow from this source".
  3. Install the APK: Open your browser's downloads list or your device's File Manager app, select the downloaded {{ .product }}_vx_x_x.apk file, and tap Install.
  4. Play Protect Verification: These builds are signed by our developers rather than distributed through an app store, so Google Play Protect may warn about an unrecognized signature. Before dismissing that warning, verify the file: compare the SHA-256 and signing certificate shown under "Verify this download" above with the file you downloaded. If either value differs, do not install — delete the file and email support@gnitoapp.com. If they match, tap "More Details" and choose "Install Anyway".
