Compare the hash of the file you actually downloaded with the value above.

  • On a computer (or after copying the file to one): sha256sum {{ .apk.apk }} on Linux/macOS, Get-FileHash {{ .apk.apk }} in Windows PowerShell.
  • On Android there is no built-in checksum tool. Install Termux and run sha256sum /sdcard/Download/{{ .apk.apk }} (in Termux, ~/storage/downloads after termux-setup-storage), or use a reputable checksum app from your app store.

The hash must match exactly; the full list is in SHA256SUMS. The certificate fingerprint is what apksigner verify --print-certs reports for the file (advanced check on a computer) — it identifies the signing key, while the hash identifies the exact file. A different hash or certificate means this is not the build published here: do not install it, and report it to support@gnitoapp.com.
