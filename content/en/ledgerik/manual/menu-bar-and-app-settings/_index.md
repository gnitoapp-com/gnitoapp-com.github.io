Three menus run across the top of the Ledgerik window: **File**, **Windows** and **Help**.

**App Settings** is the fourth item of the File menu. It opens the preferences.

Everything here is described in the order it appears.

## File

- **New** — asks for a name and a folder, then creates a company file. [Company Files](/ledgerik/manual/company-files/) has the procedure.
- **Open** — opens an existing company file.
- **Close** — closes the open company. The file stays where it is. Nothing is deleted.
- **App Settings** — opens the preferences window described below.
- **Exit** — quits Ledgerik.

There is no recent-files list. There is no print command. There is no import or export here.

Importing lives under **Company Data ▸ Import Data**. Printing belongs to the window you are in.

## Windows

- **Stack Windows** — tidies the windows you have opened back into place on the canvas.
- **Close All** — closes every open window at once.

Your data is not affected by either. Only the windows close.

Both entries are greyed out while no window is open.

The canvas itself is covered in [Getting Started](/ledgerik/manual/getting-started/). It explains opening, moving, resizing and closing a window.

## Help

- **User Help** — opens this manual in your browser. The manual is the application's help. Nothing else needs installing to read it.
- **Support** — opens the support page.
- **License** — opens the licence dialog. That is where a key is entered, or a licence released. [Licensing](/ledgerik/manual/licensing/) covers activation.
- **About** — shows the application name and icon. It also shows the copyright line with the current year, and buttons for the **Terms of Service** and the **Privacy Policy**.

## App Settings

**App Settings** opens a window with four tabs: **Date**, **Appearance**, **Language** and **License**.

Every change is saved as soon as you make it. It takes effect immediately. It belongs to this installation, not to the company you have open.

### Date

- **App Date** — the date Ledgerik works from. It can differ from the system date. Choose it deliberately. The home screen shows it, and new records take their default dates from it.
- **Date Format** — the format used for entering and displaying dates throughout the application.

### Appearance

- **Dark Mode** — switches the whole application between the dark and light appearance.
- **Color Palette** — **Vibrant**, **Pastel**, **Neutral** or **Monochrome**.
- **Seed color** — the colour the palette is built from. Pick a new one and every accent follows.
- **Number Format** — how numbers are displayed and parsed: thousands separators and the decimal mark.

### Language

- **System** — follow the language of the operating system.
- **English**, **German**, **French**, **Spanish** — choose one explicitly.

The choice applies at once. No restart is needed. Anything not yet translated stays in English.

### License

The tab shows four details:

- **Status** — the licence you are on.
- **License Key** — the key you entered.
- **Issued** — when it was issued.
- **Last Validated** — when it was last checked.

It also has a **Manage License** button.

On Ledgerik Basic the tab offers the upgrade instead. **Manage License** is still where a key is entered — see [Licensing](/ledgerik/manual/licensing/).

## Why these settings do not travel

Everything in App Settings belongs to the installation. The date pattern, the language, the colours and the number format live on this computer. They are not stored inside the company file.

Open the same company on another machine. Your appearance choices stay behind. The books arrive intact.

The settings that do belong to the company are its name, fiscal year, base currency and accounts. They live under **Company Settings**, described in [Company Settings](/ledgerik/manual/settings/).
