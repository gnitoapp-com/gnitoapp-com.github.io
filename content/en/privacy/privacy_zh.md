### 我们是谁

GnitoApp.com 是 3827992 Canada Inc. 使用的名称。本政策适用于本网站（gnitoapp.com）以及我们发布的应用程序——Units2Units、Force Workout Helper 和 Romanitaire（合称“这些应用”）。

### 简要说明

- **无需账号。** 应用可离线使用，从不需要您注册或登录。
- **没有广告，也没有广告或分析类 SDK。**
- **您在应用中输入的内容只保存在您的设备上。**
- 只有四类信息会离开设备，且每类都有明确原因：崩溃诊断、购买处理、版本检查，以及仅限 Units2Units 的汇率请求。
- **本网站不设置 Cookie，也不运行任何分析工具。** 我们的托管方会保留标准的服务器日志，这与任何 Web 服务器一样。

### 关于应用

#### 您输入的信息

换算结果、计时器、设置和收藏内容都保存在您的设备上，我们无法读取。卸载应用即会删除这些内容，除非设备的备份系统另行保存了副本。

#### 崩溃诊断（三个应用均有）

如果应用崩溃或出现意外错误，会向我们的错误监控服务商 Sentry 发送一份技术报告。报告包含错误信息及其调用栈、应用版本与构建号、设备型号与操作系统版本，以及出错时应用的状态。报告中**不包含**您的姓名、电子邮件地址或任何账号标识——我们本来就没有这些信息。我们不会在报告中附加默认的个人数据，也不会将其与个人关联；报告仅用于定位并修复缺陷。

#### 购买（仅 Units2Units，可选）

可选的 Pro 升级是这些应用中唯一涉及个人数据的功能，且为可选。付款由 RevenueCat 及其支付服务商处理——iOS 上为 Apple App Store，Android 上基于 Web 的购买为 Stripe。这些服务商会获得完成支付所需的信息（例如电子邮件地址和支付方式）并保留购买记录；我们只会收到升级已生效的确认，不会收到您的银行卡信息。上述处理受这些服务商各自的隐私政策约束。

#### 版本检查（三个应用均有）

每个应用都会向本网站查询是否有新版本。该请求包含您的 IP 地址，我们的托管方会将其记录在服务器日志中。我们仅用它提供正确的版本信息，不会用来识别您的身份。

#### 汇率（仅 Units2Units）

货币换算功能会从 open.er-api.com 获取汇率。该服务商会看到请求及您的 IP 地址，但不会知道您换算的内容。

### 关于本网站

本网站不使用 Cookie、不运行分析工具、不含跟踪像素，也没有联系表单。网站托管于 GitHub Pages，其会依据 GitHub 自身的隐私声明保留标准服务器日志（IP 地址、浏览器标识、请求的网址）。APK 下载提供已公布的 SHA-256 校验值和签名证书指纹，以便您验证所得文件。如果您给我们发邮件，我们会收到您主动提供的内容。

### 我们不会做的事

我们不出售、出租或交换个人信息；不进行用户画像；不跨应用或网站跟踪您；不使用广告标识符；也不访问您的位置、通讯录、照片或文件。

### 数据保留期限

- **崩溃报告**由 Sentry 在有限期限内保留，随后删除。
- **购买记录**由 RevenueCat、Apple 或 Stripe 按其保留政策保存；我们只保留履行购买所需的最少信息。
- **支持邮件**在问题处理期间及之后一段合理时间内保留。
- **服务器日志**由 GitHub 按其保留政策保存。

### 您的权利

根据您所在地区的法律（例如加拿大的 PIPEDA、欧洲经济区及英国的 GDPR），您可以要求我们提供所持有的个人信息的副本、更正或删除这些信息、停止某项使用，并可随时撤回同意。请写信至 **legal@gnitoapp.com**；我们可能要求您确认身份，并在合理期限内答复。您也可以向加拿大隐私专员公署或当地监管机构投诉。

由于这些应用无需账号，且您的内容保存在设备上，对许多请求而言，诚实的答复会是：我们并不持有您的个人信息。

### 儿童

这些应用并非面向 13 岁以下儿童，我们也不会在知情的情况下收集儿童的个人信息。如果您认为儿童向我们发送了个人数据，请联系我们，我们会将其删除。

### 安全

我们全程使用 HTTPS，尽量减少持有的数据，并公布每个 Android APK 的签名证书，以便您验证其来源。任何系统都无法做到绝对安全，我们无法保证绝对的安全性。

### 其他网站

应用和本网站会链接到第三方——Apple App Store、Bluesky、GitHub 以及 3827992canadainc.com。它们的行为适用其各自的隐私政策，本政策不适用。

### 政策变更

当应用或网站的实际行为发生变化时，我们会更新本页面，页面顶部的日期为准。重大变更也会在首页说明。
